About This Site Waa'ee Marsariitii Kanaa

Oromo News & Views is an independent platform dedicated to sharing timely news, cultural stories, and diverse perspectives from the Oromo community — both within Oromia and across the global diaspora.

Our mission is to inform, connect, and amplify Oromo voices in a rapidly changing world. We cover politics, economics, education, culture, sports, and human rights with a commitment to accuracy and community service.

This site is built as a simple, open-source static website so that it loads quickly on any device and can be hosted freely on GitHub Pages. Contributions and feedback are welcome via the GitHub repository.

Oduu fi Yaada Oromoo marsariitii bilisaa kan oduu yeroo isaa, seenaalee aadaa, fi ilaalcha garagaraa hawaasa Oromoo irraa qooduu hundaa'e — Oromiyaa keessattis ta'e diasporaa addunyaa guutuu.

Kaayyoon keenya sagalee Oromoo beeksisuu, walitti hidhuuf fi guddisuuf jira. Siyaasaa, diinagdee, barnoota, aadaa, ispoortii fi mirga namoomaa hawwii sirrii fi tajaajila hawaasaatiin hordofna.

Marsariitiin kun akka marsariitii saatatiikii salphaa, madda banaa kan meeshaa kamiyyuu irratti saffisaan banamu fi GitHub Pages irratti bilisaan qabatamu ijaarame. Galtee fi yaada GitHub repository irraa simataama.
