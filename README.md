# France & Africa | Commentary and Analysis

A fast, static editorial website focused on commentary and analysis about why France is changing its relationship with Africa.

---

## 🚀 View the Live Site

- Main homepage: `https://yabo1234.github.io/oromo3.html/`
- Secondary page: `https://yabo1234.github.io/oromo3.html/oromo3.html`

> Note: GitHub Pages shows the version currently deployed from the publishing branch. If your Pages site is still publishing from `main`, the live site may not reflect the new changes until this branch is merged or the Pages source is updated.

---

## 🧭 Site Focus

This project was recreated into a cleaner editorial site with a unified political-analysis theme.

It now centers on:

- **Overview** of France–Africa relations
- **Commentary** on why the relationship is changing
- **Key Drivers** such as sovereignty, military setbacks, economic pressure, and new geopolitical competition
- **Debate** over whether the shift is genuine transformation or strategic repositioning
- **About** section describing the purpose of the site

## 💻 View Locally

No build step or framework is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/yabo1234/oromo3.html.git
   cd oromo3.html
   ```
2. Open either page in your browser:
   - `index.html`
   - `oromo3.html`

Examples:

```bash
open index.html
```

or

```bash
open oromo3.html
```

You can also drag the files directly into a browser window.
